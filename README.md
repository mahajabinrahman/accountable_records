# accountable_records
Tools for analyzing law enforcement data, including deduplication/record-linkage pipelines to match identities, and NLP analysis of civilian cases -- both streamlined for human judgement. 

* Note: This repository is currently being updated, but to test the tiered linkage code, please download "testdata.xlsx" (excel file) and the corresponding notebook "tiered_record_linkage.ipynb" into the same directory. Feel free to refresh my outputs in order to test the code with different thresholds, or make edits if you want to use a dataset with different categories/column names.
